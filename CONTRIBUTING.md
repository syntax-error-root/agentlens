# Contributing to AgentLens

Thank you for contributing to AgentLens.

## Development Workflow
- Follow the System-1 Architect Governance and ADR specifications.
- Monorepo crates must adhere to the Layer 0–4 DAG and `#![forbid(unsafe_code)]`.
- Run formatting, clippy, and tests prior to opening PRs.
- Adhere to Conventional Commits.
